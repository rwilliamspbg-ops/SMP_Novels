Quick Start

Initialize the Aegis Core in under 5 minutes.

bash — setup.sh
# 1. Clone and setup environment
git clone https://github.com/rwilliamspbg-ops/SMP_Novels.git
cd SMP_Novels && cp .env.example .env
# 2. Generate strong JWT secret (required!)
node -e "console.log(require('crypto').randomBytes(64).toString('hex'))" >> .env
# 3. Build and start the stack
docker-compose -f docker-compose.prod.yml up --build -d
# 4. Check health endpoints
curl http://localhost:3001/ping # Backend API
curl http://localhost:3001/sandbox # WASM Sandbox
curl http://localhost:3000/ # Frontend UI
bash — dev-mode.sh
# Local backend development (without Docker)
cd backend
npm install
cp .env.example .env # Edit with your secrets
node src/server.js # Run on port 3001
# Local frontend development
cd frontend
npm install
npx serve . # Simple static server

Security Hardening

Defense in depth across all layers of the stack.

Helmet.js

Security headers including CSP, HSTS, X-Frame-Options, and X-Content-Type-Options.

CORS Protection

Strict cross-origin resource sharing policies with whitelist validation.

Rate Limiting

60-second window with 100 request maximum per IP to prevent abuse.

Multi-stage Docker

Minimal attack surface with distroless final images and non-root container users.

Resource Limits

Container constraints: 2 CPU cores maximum, 1GB memory limit per service.

Health Checks

Automated container health monitoring with restart policies and readiness probes.
